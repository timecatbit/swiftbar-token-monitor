# Mac 怎么选

1. 点击苹果菜单  → **关于本机**。
2. 显示「芯片：Apple M…」：下载文件名带 **AppleSilicon-arm64** 的 DMG。
3. 显示「处理器：Intel…」：下载文件名带 **Intel-x64** 的 DMG。

打开 DMG，把 **Token Monitor** 拖到 **应用程序**，推出镜像，再从应用程序打开。菜单栏会出现星星；左键看用量，右键管理主页模块、登录启动和通知。独立版自带运行环境，不用先装 SwiftBar 或 Python。

已经在用 SwiftBar？也可以继续用插件版。发布页列出了两种方式；插件 ZIP 不区分 Apple 芯片和 Intel。两版共用本机设置和 Key，建议同一时间只运行一个，避免重复图标、提醒和请求。换用独立版前，在 SwiftBar 中停用此插件即可，不需要删除 SwiftBar。

正式发行是否经过 Apple 公证，以该版本 Release 和 DMG 内的说明为准。未公证的测试包仅从项目的 GitHub 下载并核对校验值；首次打开时，macOS 可能要求到「系统设置 → 隐私与安全性」确认。
